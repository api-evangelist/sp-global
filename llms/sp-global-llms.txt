# S&P Global

> S&P Global's public developer surface is anchored by Kensho Technologies (its AI subsidiary): the S&P Global LLM-Ready API (kFinance) exposing S&P Capital IQ financials, market data, transcripts, M&A, and funding rounds to LLMs and agents (REST + hosted MCP server), plus the Kensho Extract, NERD, and Scribe document/NLP/transcription APIs. Enterprise data products are distributed through the S&P Global Marketplace.

Authentication is OIDC on OAuth 2.0 (keypair for production, 7-day refresh tokens for development); every API accepts the resulting JWT as a Bearer token. The hosted MCP server at https://kfinance.kensho.com/integrations/mcp uses OAuth with dynamic client registration and PKCE.

## APIs

- [S&P Global LLM-Ready API (kFinance)](https://docs.kensho.com/llmreadyapi): S&P Capital IQ companies, securities, statements, estimates, transcripts, mergers, funding rounds, and identifier crosswalks. Base https://kfinance.kensho.com
- [Kensho Extract](https://docs.kensho.com/extract): PDF/image to structured JSON (tables, OCR). Base https://extract.kensho.com
- [Kensho NERD](https://docs.kensho.com/nerd): named-entity recognition and disambiguation to Capital IQ IDs. Base https://nerd.kensho.com
- [Kensho Scribe](https://docs.kensho.com/scribe/v2/developer-guide): batch and real-time (WebSocket) finance-tuned transcription. Base https://scribe.kensho.com
- [Kensho Grounding Agent (Alpha)](https://docs.kensho.com/grounding/overview): retrieval with citations over S&P Global datasets.
- [S&P Capital IQ Pro](https://www.spglobal.com/market-intelligence/en/solutions/products/sp-capital-iq-pro): enterprise desktop + API platform.
- [S&P Global Marketplace](https://www.marketplace.spglobal.com): catalog for enterprise data products (API, Snowflake/Databricks shares, SFTP).
